自然语言处理核心概念笔记

一、NLP应用领域

  • 文本分类：文档类别识别
  • 情感分析：观点极性判断
  • 文本抽取：关键信息提取
  • 推荐系统：基于内容相似度

二、语言模型与词向量

1. 基本概念

语言模型本质：给定历史词预测下一词的概率分布
$P(s) = P(w_1, w_2, \dots, w_n) = \prod_{i=1}^n P(w_i|w_1,\dots,w_{i-1})$

2. 马尔可夫假设

类型公式特点
k阶马尔可夫链$P(w_i|w_{1:i-1}) \approx P(w_i|w_{i-k:i-1})$依赖固定长度历史
概率计算$\frac{\text{count}(w_{i-k:i})}{\text{count}(w_{i-k:i-1})}$统计频次

3. 数据稀疏解决方案

1P_{\text{smooth}} = 
2\begin{cases} 
3\frac{\text{count}(·)+1}{\text{count}(·)+|V|} & \text{(拉普拉斯平滑)} \\
4\alpha P_{\text{high}} + (1-\alpha)P_{\text{low}} & \text{(回退策略)}
5\end{cases}

4. 评价指标

  • 困惑度(Perplexity)：
    $\text{PP}(s) = \exp\left(-\frac{1}{n}\sum_{i=1}^n \log P(w_i|w_{<i})\right)$

    值越小表示模型预测越确定

GloVe创新点

核心公式：
$J = \sum_{i,j} f(X_{ij})(\mathbf{v}i^\top \mathbf{u}j + b_i + c_j - \log X{ij})^2$
*[补充：$f(x)=\begin{cases}(x/x{\max})^\alpha & x<x_{\max}\1 & \text{otherwise}\end{cases}$ 控制高频词权重]*

四、RNN与Seq2Seq架构

1. RNN基本结构

1graph LR
2A[t-1状态] --> B[tanh]
3C[t输入] --> B
4B --> D[t状态]
5D --> E[输出]
6D --> A

梯度问题：
$\frac{\partial h_t}{\partial h_1} = \prod_{k=1}^{t-1} \frac{\partial h_{k+1}}{\partial h_k}$ → 梯度消失/爆炸

2. Seq2Seq缺陷

1graph LR
2S[我 来自 中国] --> Encoder
3Encoder --> V[单一上下文向量]
4V --> Decoder
5Decoder --> T[I from China]

瓶颈：长序列信息压缩丢失 → 注意力机制解决

3. 注意力机制

计算流程

  1. 编码器隐状态：$H = [\mathbf{h}_1,\mathbf{h}_2,\dots,\mathbf{h}_T]$
  2. 解码器$t$时刻状态：$\mathbf{s}_t$
  3. 能量值计算：
    $e_{ti} = \mathbf{s}_t^\top \mathbf{W}_a \mathbf{h}_i$ [补充：双线性变换增强表达能力]
  4. 注意力分布：$\alpha_{ti} = \frac{\exp(e_{ti})}{\sum_j \exp(e_{tj})}$
  5. 上下文向量：$\mathbf{c}t = \sum_i \alpha{ti} \mathbf{h}_i$

2. 核心技术创新

位置编码

$\text{PE}(pos,2i) = \sin(pos/10000^{2i/d})$
$\text{PE}(pos,2i+1) = \cos(pos/10000^{2i/d})$

[补充：$d$为向量维度，奇偶维度交替使用sin/cos]

多头注意力

$\text{MultiHead} = \text{Concat}(\text{head}_1,\dots,\text{head}_h)\mathbf{W}^O$
$\text{head}_i = \text{Attention}(\mathbf{QW}_i^Q, \mathbf{KW}_i^K, \mathbf{VW}_i^V)$

层归一化

$\text{LayerNorm}(\mathbf{x}) = \gamma \frac{\mathbf{x}-\mu}{\sqrt{\sigma^2+\epsilon}} + \beta$

沿特征维度归一化，加速收敛

2. Beam Search算法

1\text{Score}(y_{1:t}) = \sum_{k=1}^t \log P(y_k|y_{1:k-1}, \mathbf{x})

执行过程

  1. 初始化：k个空序列，分数=0
  2. 扩展：为每个序列生成Top-N候选
  3. 修剪：保留总分数最高的k个序列
  4. 终止：所有序列生成<EOS>时停止

平衡点：

  • Beam Size ↑ → 效果↑计算成本↑
  • Beam Size ↓ → 效率↑质量↓
