def expanded_form(num):
    num_str = str(num)
    a=0 
    l=[]
    for i in num_str:
        if(i=='0'):
            a+=1
            continue
        l.append(i+'0'*(len(num_str)-a-1))
        a+=1
    return ' + '.join(l)

解法一

使用enumerate和列表推导式 (List Comprehension)

def expanded_form(num):
    num = list(str(num))
    return ' + '.join(x + '0' * (len(num) - y - 1) for y,x in enumerate(num) if x != '0')
  • enumerate() 函数
    • 这是代码中手动维护 a=0、a+=1 的完美替代品。
    • enumerate 的作用是在遍历一个序列（如列表、字符串）时，同时返回元素的“索引”和“值”
    • 在这份答案中，for y,x in enumerate(num) 就是在遍历 num 字符串时，y 得到了索引（相当于你的 a），x 得到了每个数字字符（相当于你的 i）。这样就不用自己去管理索引了。
  • 列表推导式
    基本语法为：[expression for item in iterable if condition]

def expanded_form(n):
    result = []
    # 从高位到低位遍历 (例如 70304 -> 从 10000 开始)
    for a in range(len(str(n)) - 1, -1, -1):
        current = 10 ** a  # current 依次是 10000, 1000, 100, 10, 1
        quo, n = divmod(n, current) # 核心！
        if quo: # 如果商不为0
            result.append(str(quo * current))
    return ' + '.join(result)

  • range(start, stop, step)
    range(len(str(n)) - 1, -1, -1) 的意思是创建一个从 数字长度-1 开始，每次递减 1，直到 -1（但不包括-1）的序列。
    例如，对于 70304，len 是 5。range(4, -1, -1) 会产生序列：4, 3, 2, 1, 0。
    10 ** a 就会依次得到 10000, 1000, 100, 10, 1，正好是每一位的权重。

  • divmod(a, b) 函数
    divmod 是 “division” (除法) 和 “modulo” (取模) 的缩写。它非常高效，能同时返回商和余数
    quotient, remainder = divmod(a, b) 等价于：
    quotient = a // b
    remainder = a % b

  • 两个乘号 **

def expanded_form(num):
    num = str(num)
    st = ''
    for j, i in enumerate(num):
        if i != '0':
            st += ' + {}{}'.format(i, (len(num[j+1:])*'0'))
    return st.strip(' +')
  • 字符串切片 num[j+1:]
    字符串 num 的第 j+1 个位置开始，一直取到字符串的末尾
  • .format() 字符串格式化
    ‘{}{}’.format(a, b) 是将变量 a 和 b 填充到字符串的 {} 占位符中。这是一种比用 + 拼接更推荐的字符串构建方式。

  • .strip() 方法
    因为它的循环逻辑是 st += ’ + …’，所以第一次添加时，字符串的开头就会多出一个 ’ + ‘，例如 + 70000 + 300 + 4。
    st.strip(’ +’) 的作用是移除字符串开头和结尾的所有空格和 + 号，把多余的部分清理干净。
